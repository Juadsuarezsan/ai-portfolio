# Blog drafts

These are the per-project technical write-ups. Each is ≥800 words, focused on
the non-obvious engineering decisions, and ready to paste into Medium /
Dev.to / personal blog.

Drafts shipped:
- [01 — E-commerce Assistant](./01-ecommerce-assistant.md) (~1100 words)
- [02 — Support Triage](./02-support-triage.md) (~900 words)

Remaining (P3 – P9) — outline-stage. Use the structure of the first two as a
template:

1. **The problem** (real industrial use case in 2-3 sentences)
2. **The naive answer** + why it fails
3. **The technique that actually works** (the architectural insight)
4. **Cost & latency math** (the part hiring managers actually read)
5. **What's next** (path to v1.0.0)

When ready to publish:
- Copy to Medium / Dev.to
- Update LinkedIn with link + 2-3 lines summary
- Update the project README with the published link
